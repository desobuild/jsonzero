# Design Reference & Screen Mockups

This directory contains the approved UI design screens and mockups for **JSONZero**.

## Screens

- `screens/01-main-workbench.svg` — Main workbench interface with editor, toolbar, privacy badge, and status bar
- `screens/02-more-tools-menu.svg` — More tools dropdown menu showing categorized tool actions
- `screens/03-error-presentation.svg` — Error presentation and validation error reporting
- `screens/04-diff-comparison.svg` — Visual diff comparison view
- `screens/05-json-search.svg` — JSON search and filtering view
- `screens/06-tree-view.svg` — Interactive tree view representation
- `screens/07-batch-processing.svg` — Batch operations interface
- `screens/08-settings-preferences.svg` — Preferences and configuration drawer
- `screens/09-mobile-responsive.svg` — Responsive mobile layout

## Design System Tokens

The application design tokens defined in `src/styles/index.css` are extracted directly from these approved SVG specifications:

- **Theme Palette**: Deep slate/dark background (`#12131A`), surface (`#1A1B22`), elevated surface (`#1E1F26`), overlay (`#33343C`), and border (`#292931`).
- **Accent**: Emerald green (`#68DBA9`) representing privacy, safety, and client-side isolation.
- **Typography**: Geist Sans for interface UI and Geist Mono for code/JSON payloads.
