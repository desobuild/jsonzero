# Support & Community Help

Thank you for using JSONZero!

## Documentation

Before opening an issue, check the project documentation:
- [README.md](./README.md) — Quick start, feature guide, and development commands.
- [Architecture Guide](./docs/architecture.md) — Technical details of the frontend, workers, and offline capabilities.
- [Privacy Policy](./docs/privacy.md) — Explanation of client-side local processing and zero-network guarantees.
- [Deployment Guide](./docs/deployment.md) — How to build and deploy JSONZero to static hosts like Cloudflare Pages.
- [Known Limitations](./README.md#known-limitations) — Current operational limits and browser compatibility notes.

## Asking Questions & Discussions

For general questions, how-tos, or workflow ideas:
- Open a discussion on [GitHub Discussions](https://github.com/desobuild/jsonzero/discussions).
- Search previous discussions and closed issues first.

## Reporting Bugs

If you find a bug:
1. Ensure your issue has not already been reported by searching [GitHub Issues](https://github.com/desobuild/jsonzero/issues).
2. Open a bug report using our [Bug Report Template](https://github.com/desobuild/jsonzero/issues/new?template=bug_report.yml).
3. **Privacy Reminder**: Never post sensitive credentials, API keys, personal data, or confidential JSON payloads. Always use synthetic sample data.

## Requesting Features

To suggest new tools or enhancements:
1. Open a feature request using our [Feature Request Template](https://github.com/desobuild/jsonzero/issues/new?template=feature_request.yml).
2. Keep in mind JSONZero's core design philosophy: zero server uploads, 100% client-side execution, no analytics/telemetry, and zero clutter.

## Security Disclosures

For security vulnerabilities, please refer to our [Security Policy](./SECURITY.md). Do not submit security reports as public issues.
